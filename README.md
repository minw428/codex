# 일본 가족여행 2026

2026년 11월 25일–12월 2일 도쿄·교토·오사카 3인 가족여행의 모바일 일정표입니다.

## 포함된 정보

- 날짜별 시간표, 선택 관광지, 비·피로 대안과 날짜별 대표 풍경 이미지
- 식사마다 후보 5곳(호텔 조식 제외), 한·일 표기, 음식 종류, 1인 예상 가격, 타베로그 정보와 Google Maps 링크
- 초행자를 위한 주요 이동 경로, 항공편과 숙소, 출발 전 준비 목록
- 모바일 반응형 화면과 홈 화면 설치용 PWA

여행 날짜·항공편·숙소명만 공개합니다. 이름, 예약번호, 승차권 정보는 넣지 않았습니다. 호텔 예약 상태, 조식 포함 여부, 열차 시각, 식당 영업과 가격은 확정 정보가 아니므로 출발 전 다시 확인해야 합니다.

`docs/food-illustrations.png`는 음식 종류를 구분하기 위한 20종의 캐리커처풍 일러스트입니다. 라멘과 츠케멘은 별도 그림을 사용합니다. `docs/day-atlas.png`는 8일의 AI 생성 대표 풍경입니다. 그림은 실제 식당 메뉴나 현지의 기록 사진이 아닙니다. 식당의 실제 사진은 각 Google Maps 링크에서 확인하세요. 두 이미지는 사이트 안에서 재사용하며 첫 방문 후 오프라인에서도 볼 수 있게 캐시합니다. 외부 지도와 타베로그는 인터넷 연결이 필요합니다.
